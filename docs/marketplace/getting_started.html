Welcome to Cliq!

Cliq is your graphical bridge between powerful AI agents (like Claude and Gemini CLI) and your IDE. Here is how to get up and running in 3 minutes:

1. Configure your CLI agents

Go to Settings | Tools | Cliq. Add as many CLI agents as you like, each with its own command, arguments, environment variables, and working directory. A few defaults are pre-configured to get you started:

  • Claude: claude
  • Gemini: gemini
  • Qwen: qwen

2. Launch an Agent

Use the Run Cliq Agent action in the main toolbar or press Ctrl+Alt+Q. This opens a new session in your IDE terminal with full Cliq integration. Prompts and @-context are only ever typed into terminal tabs Cliq started this way, so start an agent before sending anything.

3. Share Context

Select files in the Project View, right-click, and choose Send Files as @-Context. Your agent will immediately "see" these files and be able to reason about them.

4. Reuse Prompt Templates and History

In the Cliq tool window, click the template icon next to the chat input to insert a saved prompt (with automatic {{activeFile}}, {{selection}}, and {{clipboard}} placeholders), or save your current input as a new template. Use the history icon to reinsert any prompt you've sent before.

5. Review Changes

When the agent proposes a code change, Cliq will open a native Diff Review tab. For larger, multi-file changes, use the Pending Changes panel in the tool window to Accept All or Reject All at once instead of reviewing files one by one. Cliq only ever writes inside your project, and only when the project is trusted.

6. Draft a Commit Message

Once you're happy with the changes, run Cliq: Generate Commit Message from the Tools menu. Cliq builds a diff of your current changes and drops a ready-to-send prompt into the chat input for your agent to turn into a commit message.
