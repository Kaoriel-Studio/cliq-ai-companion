Power Features for AI-Assisted Coding

Custom CLI Agents

Cliq no longer limits you to a fixed list of agents. Configure any number of CLI agents in Settings | Tools | Cliq, each with its own display name, executable path, arguments, environment variables, and working directory. Add, edit, duplicate, or remove agents at any time — every selector across the plugin updates instantly, no restart required. Environment values are kept in the IDE password safe and handed to the agent through its terminal session's environment, so API keys never reach your shell history.

Prompt Templates

Save your best prompts once and reuse them everywhere. Insert a saved template into the chat input with one click, or save your current input as a new template on the fly. Manage the full list (add, edit, reorder, remove) from a dedicated dialog. Templates support {{activeFile}}, {{selection}}, and {{clipboard}} placeholders that are filled in automatically on insert. Cliq ships with ready-to-use templates: Explain Code, Refactor & Optimize, Write Unit Tests, and Find Bugs.

Prompt History

Every prompt you send is kept in a per-project history. Reopen the history panel from the chat input to reinsert an earlier prompt instead of retyping it, or clear the history when you're done with a task.

Model Context Protocol (MCP) Support

Cliq implements a local MCP Server directly inside your IDE. This allows any AI agent that supports the protocol to:

  • Read your open files and cursor position in real-time.
  • Propose complex, multi-file changes through a unified interface.
  • Interact with IDE tools (like terminal and file management) securely.

Intelligent @-Context System

No more manually copying and pasting code! Cliq uses a specialized @filename token system to feed your files into the agent's context window efficiently. Use the Cliq Tool Window to manage your "pinned" context and recently opened files.

Safe & Visual Diff Reviews

Never let an AI overwrite your work without permission. Cliq's diff viewer provides:

  • Side-by-side comparison of current and proposed code.
  • Manual editing within the "Proposed" side before acceptance.
  • Single-click acceptance: the running agent applies the change, and if no agent session is listening Cliq writes the file itself so nothing is silently lost.
  • Project-scoped writes only: paths outside your project, and untrusted projects, are refused.

Pending Changes Review Queue

Large, multi-file refactors no longer mean reviewing diffs one at a time. The Pending Changes panel in the Cliq tool window lists every diff currently open from an agent session, so you can jump into any file, or click Accept All / Reject All to resolve the whole batch at once — with a confirmation step before anything is discarded.

Pull and Merge Request Review Context

Run Cliq: Collect Pull/Merge Request Context… from the Tools menu or the merge icon above the chat input, pick an open GitHub pull request or GitLab merge request (the one for your current branch is preselected) or type its number, and Cliq gathers everything a reviewer needs in the background:

  • Diffs with wide context, taken from your local git history when the commits are available (missing commits can be fetched automatically), otherwise computed with the IDE diff engine from the hosting API. For GitHub, diffs are taken against the true merge base.
  • Full file contents, related tests and dependent files found through the IDE indexes, plus build configuration of the nearest modules and CI workflow files.
  • CI status, failed job log tails, commits and review discussions with their file and line positions: GitLab pipelines, GitHub check runs and Actions logs.

The result is split into chunks that fit your agent's read limits, written to .cliq/reviews/ inside the project, pinned to the Context list, and a configurable review prompt is placed in the chat input. Choose whether a ready-made review prompt, one of your own prompt templates, or nothing is placed in the chat input. Add GitHub, GitHub Enterprise and GitLab hosts with their tokens (kept per project unless you enable sharing), and configure proxy bypass, collection limits and extra secret keywords, in Settings | Tools | Cliq | Code Review. The commit-message action now lives in the tool window menu and the Tools menu.

AI-Drafted Commit Messages

Run Cliq: Generate Commit Message from the Tools menu to build a diff of your current changes and drop a ready-to-send prompt into the Cliq chat input. Pick your agent and send it to get a commit message drafted from your actual changes, then copy it into your commit dialog.
